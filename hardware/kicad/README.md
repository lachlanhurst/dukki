# KiCad library: WeAct STM32G474 core board

Footprint and symbol for the WeAct Studio STM32G474 core board V1.0, LQFP48 (CBT6/CET6) variant, the bridge MCU board in this project. Generated by `scripts/kicad/gen_weact_kicad.py` from WeAct's board outline drawing and schematic in `docs/datasheets/`. Edit the script, not the files.

Files:

- `WeAct_STM32G474CoreBoard.pretty/WeAct_STM32G474CoreBoard_LQFP48.kicad_mod`, the footprint. KiCad 8 format.
- `WeAct_STM32G474CoreBoard.kicad_sym`, the matching symbol, pin names as on the board silkscreen.
- `3d/`, place for WeAct's STEP model, not committed (7 MB). Fetch it with:

```sh
curl -L -o hardware/kicad/3d/WeAct-STM32G47xCxTxCoreBoard_V10_3D.step \
  "https://raw.githubusercontent.com/WeActStudio/WeActStudio.STM32G474CoreBoard/master/Hardware/QFP48/WeAct-STM32G47xCxTxCoreBoard_V10_3D.step"
```

Adding to a project: Preferences, Manage Footprint Libraries, add `${KIPRJMOD}/../hardware/kicad/WeAct_STM32G474CoreBoard.pretty` with nickname `WeAct_STM32G474CoreBoard`; Manage Symbol Libraries, add the `.kicad_sym` with the same nickname. The symbol's footprint field already points at `WeAct_STM32G474CoreBoard:WeAct_STM32G474CoreBoard_LQFP48`. The footprint's 3D model path assumes the KiCad project lives one directory below the repo root (for example `hardware/bridge/`); adjust the path in the script otherwise.

Geometry, from the WeAct drawing:

| Item | Value |
|---|---|
| Board | 36.28 x 28.14 mm, corner radius about 2 mm (estimated) |
| Headers | two 2 x 12, 2.54 mm pitch, along the long edges |
| Outer row to board edge | 1.37 mm |
| First column to USB-C edge | 6.97 mm; last column 1.37 mm from the other edge |
| Pads | 1.7 mm round, 1.0 mm drill (KiCad pin-header convention); pads 1 and 25 square |
| Courtyard | board plus 0.25 mm, plus 1 mm on the USB-C edge for the receptacle |

Pad numbering: pads 1 to 24 are schematic connector P1, the VCC side (VCC, VCC, GND, GND, PB12, PB13, ...), pads 25 to 48 are P2, the 3V3 side (3V3, 3V3, GND, GND, PB10, PB11, ...). Odd pads are the inner row and even pads the outer row, matching the silkscreen pairs. Every pad carries its pin name as the pad function, so hovering in pcbnew shows it. The QFN48 variant of the board has the same outline and grid; it differs only in the four positions that are NC here (PC4, PC6, PC10, PC11 there).

Not yet verified by opening in KiCad; the files were generated and checked structurally. Open the footprint in the editor once and run DRC on the first board that uses it.

Community alternatives found (KN-NaMi/Tip-Etcher and Patryk2k04/NaMi_DevBoard on GitHub) are drawn for the QFN variant, carry no licence and use a 0.76 mm drill, which does not accept a 0.64 mm square header pin. Not used.
